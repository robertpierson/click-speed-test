# Reflex Test — God Tier Edition

An ultra-polished, zero-dependency reaction time game built with vanilla HTML, CSS, and JavaScript. Test your reflexes, build your combo streaks, and chase the ultimate high score. 

## Features
* **🔥 Combo System:** Chain together sub-250ms reaction times to build a "Fire Streak."
* **⚡ 3D Parallax Tilt:** Dynamic glassmorphism UI that tracks your mouse for a premium feel.
* **📱 Haptic & Audio Feedback:** Physical vibrations (on supported mobile devices) and custom Web Audio API sounds.
* **🛡️ Anti-Cheat:** Bot and guess detection for impossible reaction times (under 40ms).
* **💾 Persistent Stats:** Automatically tracks and saves your Best, Last, and Average times locally.
* **🎨 Next-Gen UI:** Breathing background gradients, smooth Web Animations API (WAAPI) transitions, and fully responsive design.

## How to Play
1. Click anywhere or press **Space** to begin.
2. Wait for the screen to turn green (Hold steady!).
3. Click or press Space as fast as humanly possible. 
4. *Don't pull the trigger too early, or you'll misfire and lose your streak!*

## Setup
Just open `index.html` in any modern browser. No build steps, no frameworks, no dependencies.
